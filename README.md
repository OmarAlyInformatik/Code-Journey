# 🚀 Code-Journey

Willkommen in meinem Lern-Repository! Hier vertiefe und festige ich mein Programmierwissen, indem ich die praxisnahen Aufgaben und Tracks von **Exercism** löse, mich von **Gemini** begleiten lasse und den Code in **VS Code** entwickle.

---

## 🎯 Ziel des Projekts

Anstatt Aufgaben nur oberflächlich zu bearbeiten, löse ich hier echte Programmierprobleme (_Exercises_) in einer lokalen Entwicklungsumgebung.

Exercism bietet strukturierte Tracks mit wachsendem Schwierigkeitsgrad. So lerne ich:

- Echten Code in **VS Code** zu schreiben, lokal zu testen und zu refaktorn
- Mit KI als Tutor und Impulsgeber zu arbeiten (für Erklärungen, Code-Reviews und Best Practices)
- Git & GitHub für die Dokumentation und Versionsverwaltung meines Lernfortschritts zu nutzen

---

## 🔄 Mein Workflow

1. **Exercise wählen:** Eine Aufgabe aus einem Exercism-Track auswählen.
2. **Lösen:** Die Aufgabenstellung in **VS Code** öffnen und den Code eigenständig implementieren.
3. **Testen:** Die lokalen Tests ausführen, um sicherzustellen, dass alles funktioniert.
4. **Code-Review:** Den Code von Gemini überprüfen lassen, um Optimierungspotenziale und idiomatisches Vorgehen zu lernen.
5. **Git Commit:** Den gelösten Code hier im Repository hochladen.

---

## 🛠️ Verwendete Tools & Technologien

- **Lernplattform:** Exercism
- **KI-Assistent:** Google Gemini
- **IDE:** Visual Studio Code
- **Versionsverwaltung:** Git & GitHub
